## 可重現的檢查

`g10-audit.json` 記錄每個範圍的全部 ID、繁中名、英文名、分類與來源；`HistoricalOnly` 列出只由舊版實測支持的項目。原始公開網頁網址、固定版本與下載雜湊見 `catalog-sources.json`。

建置器遇到無法辨識的掉落名稱、模糊名稱、無效 ID 或獎勵區段缺失會失敗。驗證程式逐項斷言灰機 193 筆分區紀錄全部存在且來源正確，並檢查外場不混入 G9 樂譜、深層限定寵物不混入運河、深層地圖不能丟棄、外場需本區手動啟動。

本機客戶端可驗證物品名稱、分類、可丟棄性及區域 ID，不能據此證明該物品目前仍掉落。尚未完成遊戲內逐項掉落驗證，也沒有可證明無遺漏的伺服器獎勵全集；不能將這次修正標示為「現版全掉落驗證完成」。
